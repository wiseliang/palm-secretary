# Android 0.13.11 — 直连下载兼容

- 主站授权跳转后，精确放行 https://download.wiseliang.cloud/api/files/direct 的带票据下载。
- 继续使用 Android 系统下载器，保存到“下载”目录；不把主站登录 Cookie 主动传给下载域名。
- 下载域名的其他路径、端口和协议不作为可信 App 页面放行。
- 旧版可能把跨域下载交给系统浏览器；安装本版保持 App 内的下载触发流程。服务器启用直连即可改善传输路线，升级 APK 用于交互兼容。

使用与 0.13.10 相同的本机 debug 内测签名；尚未在用户手机实测。签名冲突时不要卸载旧版。
