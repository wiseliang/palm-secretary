# v0.16.0：自动核对执行结果

## 行为变化

- 服务重启或 Codex 连接中断后，尚未确认结束的请求保留为待核对，并保留执行前的成果快照。
- 每 15 秒检查运行中或待核对任务；读取任务列表时也会触发受间隔限制的后台核对。
- 已取得执行编号时按编号匹配；编号丢失时，仅在提交前历史与本次输入摘要能够唯一确定新执行记录时恢复状态。
- 新对话历史暂不可用时仍允许正常提交，但不推断缺少编号的请求。历史缺失、状态未知、匹配不唯一时继续保留阻塞，不自动重跑。
- 待核对任务增加“重新核对执行历史”按钮，保留人工核对入口。人工处理后的结果不会被晚到的核对覆盖。
- 完成事件优先采用执行记录中的实际状态，避免把失败执行误记为完成。
