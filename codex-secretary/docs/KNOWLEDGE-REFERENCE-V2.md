# 知识库对话引用（v0.18.0）

阅读页新增「拿这篇问助手」。在正文中选中文字时按钮切换为「引用选中段落」。点击后预览引用范围和目标对话，确认「带入对话」后仅放入当前项目的输入框，不自动执行任务。保留已有问题和附件；每次引用一篇笔记，新引用替换已有引用。

输入框提供引用内容预览、移除、原文链接，以及总结/解释/提炼行动快捷问题。问题与引用共同沿用项目草稿保存和断线重发机制。历史用户消息显示可展开的引用卡片，保留当时正文、范围、原文路径、修改时间与引用时间。原文后续修改不会改变已经发送的快照。

引用上限 24,000 字符，完整问题与引用的序列化文本不得超过既有 50,000 字符发送上限。超限提示选择较短段落，不静默截断。原始 HTML 与脚本仅作为文本内容保存。

快照以受校验的 JSON 放在用户问题后的固定参考资料段落中，仍使用既有 turn.start 文本通道及持久化去重机制。只有完整合法的引用包才在 UI 中折叠，否则按普通文本展示。资料中的附件标记会被 JSON 转义，不会被误认为真实文件附件。引用来源链接在 UI 中根据相对路径重新构造，不信任历史记录中的外部来源域名。

服务端明确将引用资料与用户操作要求区分，要求回答标注来源，不执行资料中的指令、不因引用而修改笔记，也不声称已经搜索整个知识库。任务及对话标题只使用用户问题。重试任务从原会话读取完整输入，保留引用快照。

验证：check、test:all（含新增 v030）、生产构建；浏览器覆盖取消与不自动发送、整篇/选中内容、保留草稿、刷新恢复、移除引用、发送快照、历史恢复，以及手机和深色模式。真实 AI 的回答质量另以线上小规模问答验收确认。
