# 0.17.3 — 独立 HTTPS 成果下载

- 成果下载先验证现有登录，再通过短时签名链接跳转到 download.wiseliang.cloud，绕过 Cloudflare 中转。
- 临时链接绑定项目、文件及会话，有效期最多 120 秒；注销后失效，不包含可复用的登录 Cookie。
- 直连接口支持单段 Range 续传，保留安全文件路径校验，并禁止缓存和票据 URL 访问日志。
- 页面与 Android 客户端继续使用现有下载入口，无需修改手机设置。
- Android 0.13.11 补充跨域下载兼容；旧版可能交给浏览器下载，需要保持系统下载器交互时安装兼容版。
- 独立下载域名采用公开可信 HTTPS 证书，配置自动续期与续期后的 Nginx reload。
