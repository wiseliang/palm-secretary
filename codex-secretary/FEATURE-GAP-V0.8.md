# 掌心助理与官方 Codex 功能差距（v0.8，2026-08-26）

## v0.8 已补齐

- 手机“对话 / 记录 / 文件”导航固定在顶部，不随内容滚走
- Android 系统分享入口：文件管理器、相册和其他 App 可“分享到掌心助理”，支持最多 10 个文件
- 页面前台恢复、切屏返回、网络恢复、BFCache 恢复和运行期间每 4 秒主动对账
- WebSocket 漏掉回复首帧时自动补建助手消息，不再静默丢弃后续增量

## 已具备

- 独立项目目录、项目级模型和推理强度
- 多轮对话、流式回复、停止任务、断线重连、前台恢复与消息回补
- 多文件上传、桌面拖放、Android 原生选取与系统分享、图片输入、附件随轮次展示
- 成果自动收集、预览和原生下载
- 任务记录、失败重试、文件搜索和项目隔离
- 完全访问模式、免审批执行和服务器 sudo 运维
- Web/PWA 与 Android 客户端
- Plus 账户实际模型列表，以及 5 小时/每周用量同步

## 第一优先级：影响日常可靠性

1. **系统通知与后台任务状态**：任务完成、失败、需要输入时发送 Android 通知；通知可直接回到对应项目和对话。
2. **离线任务队列**：网络中断时保存待发送内容，恢复后由用户确认重发，避免重复执行。
3. **上传续传与后台上传**：100MB 附近文件应分块、断点续传，并在 Android 通知栏显示进度。
4. **对话数据索引**：全文搜索、重命名、归档、导出、收藏和按项目过滤。
5. **冲突与重复执行保护**：每次发送具备幂等键，断线重试时明确显示“已提交/未提交”。

## 第二优先级：接近官方 Codex 工作流

1. **工具活动时间线**：折叠展示命令、文件编辑、网页操作、耗时、退出码和失败原因。
2. **变更审阅**：Git diff、逐文件修改、代码引用、接受/撤销、下载补丁及提交记录。
3. **项目生命周期**：删除/归档/复制项目，导入 Git 仓库，分支、worktree 和远程仓库同步。
4. **上下文管理**：上下文占用、自动压缩状态、从摘要继续、创建对话分支。
5. **长期任务能力**：目标、计划任务、后台队列、并发任务和定时汇报。
6. **插件生态**：MCP、连接器、Skills 和插件的可视化安装、授权与状态管理。

## 第三优先级：秘书与移动体验

- 语音输入、语音回复、相机直拍和系统扫描文档
- 分享文本、网页链接和多媒体，而不仅是外部文件
- 下载完成后打开/分享，图片画廊、PDF 分页和 Office 在线预览
- 联系人、日历、邮件、腾讯文档和网盘的受控连接
- 深色模式、字体大小、高对比度、读屏标签和横屏/平板布局
- 多账号、访客权限、审计日志和可选高风险二次确认

## 产品取舍

掌心助理应保持“手机优先的私人秘书与服务器工作台”，不机械复制桌面 IDE。建议后续顺序：

**系统通知与后台状态 → 幂等/离线可靠性 → 工具活动时间线 → Git diff → 对话搜索归档 → 插件连接器。**

官方能力参考方向包括文件输入、流式和后台任务、MCP/连接器、Skills、Shell/Computer Use，以及长期目标、项目协作与代码审查等工作流。
