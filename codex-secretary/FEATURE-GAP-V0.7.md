# 掌心助理与官方 Codex 功能差距（2026-08-26）

## 已具备

- 独立项目目录、项目级模型与推理强度
- 多轮对话、流式回复、停止任务、断线重连与消息回补
- 多文件上传、图片输入、附件随轮次持久化、成果自动收集与下载
- 任务记录、失败重试、文件预览、搜索和项目隔离
- `danger-full-access`、免审批执行以及服务器 sudo 运维
- Web/PWA 和 Android WebView 客户端
- Codex 账户实际可用模型列表
- 每 5 小时和每周用量窗口同步

## 优先补齐

1. **变更审阅**：展示 Git diff、逐文件修改、接受/撤销和下载补丁。目前只能从对话文字判断修改结果。
2. **工具活动流**：把命令、文件编辑、网页检索、耗时和失败原因以折叠卡片展示。目前主要只显示最终文本。
3. **任务后台化**：允许离开页面后持续运行，提供通知、预计耗时和完成提醒。目前虽能重连，但缺少系统通知。
4. **项目生命周期**：删除/归档项目、复制项目、导入仓库、Git 分支或 worktree。当前只有创建和重命名。
5. **上下文管理**：显示上下文占用、压缩状态、重新开始但继承摘要。当前完全由 Codex 自动处理。
6. **结构化审批**：虽然主人模式默认免审批，仍应为高风险服务器操作提供可选二次确认与审计记录。

## 后续增强

- 语音输入、语音回复与 Android 通知
- 相机直拍、系统分享“发送到掌心助理”、下载完成后直接打开
- 图片画廊、PDF 分页预览、Office 文档在线预览
- GitHub/GitLab、MCP、插件和技能的可视化管理
- 对话分支、重命名、归档、导出和全文搜索
- 计划任务、长期目标、后台队列和并发任务管理
- 终端视图、端口预览、开发服务器网页预览
- Diff/测试结果/代码引用的富文本展示
- 无障碍、高对比度、深色模式和字体大小设置

## 产品边界

掌心助理定位为“手机优先的私人秘书与服务器工作台”，不建议机械复制官方 Codex 的全部 IDE 功能。优先级应为：可靠上传下载 > 后台任务与通知 > 工具活动可见性 > 变更审阅 > Git/插件高级能力。
